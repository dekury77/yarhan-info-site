개인정보처리방침

야르한정보 업로드 도구 · 최종 갱신 2026년 9월 5일

1. 개요

이 도구는 제작자 한 사람이 자신의 영상 파일을 자신의 구글 드라이브에 올리기 위해 사용하는 개인용 도구입니다. 일반에 배포하거나 서비스로 제공하지 않으며, 제작자 외의 사용자를 두지 않습니다.

2. 수집하는 정보

이 도구는 개인정보를 수집하지 않습니다. 이용자 계정을 만들지 않고, 분석 도구나 쿠키를 사용하지 않으며, 이 웹페이지는 방문 기록을 따로 저장하지 않습니다.

3. 구글 계정 데이터의 이용 범위

도구는 구글 드라이브 API 권한(https://www.googleapis.com/auth/drive)을 제작자 본인의 계정에 대해서만 사용하며, 용도는 다음으로 한정됩니다.

  • 제작자가 만든 영상 파일을 제작자 본인의 드라이브 폴더에 업로드
  • 업로드한 파일의 이름 변경 및 삭제

드라이브의 다른 파일을 읽거나, 내용을 분석하거나, 외부로 전송하지 않습니다.

4. 데이터의 보관과 공유

파일은 제작자의 로컬 컴퓨터와 제작자 본인의 구글 드라이브에만 존재합니다. 제작자는 구글 계정 데이터를 제3자에게 제공하거나 판매하지 않으며, 광고 목적으로 이용하지 않습니다. 별도의 서버를 운영하지 않으므로 외부에 전송되어 저장되는 데이터가 없습니다.

5. 권한 철회

부여한 권한은 구글 계정의 보안 설정에서 언제든 철회할 수 있습니다. 철회하면 도구는 더 이상 드라이브에 접근하지 못합니다.

6. 변경
